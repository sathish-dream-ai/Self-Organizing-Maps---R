| Overview | Description |
| :--- | :--- |
| **What the Project Is** | An Artificial Neural Network (ANN) based Self-Organizing Maps (SOM) tool designed to analyze multi-component, multi-variable clinical trial data for traditional Indian Systems of Medicine (like Ayurveda)[cite: 2]. |
| **What It Does** | • Uses the `kohonen` package in R to project high-dimensional clinical data (45 variables per patient) onto a two-dimensional grid[cite: 5, 8].<br>• Generates visualizations (Codes Plots, Counts Plots, and Variables' Influence heatmaps) to identify natural clusters in patient responses[cite: 12].<br>• Maps the complex relationship between multiple prescribed Ayurvedic medicines and specific diabetic markers (FBS, PPBS, HbA1C) across multiple hospital visits[cite: 5, 13]. |
| **Data Source** | Retrospective clinical data from 230 diabetes patients treated at the Institute of Ayurveda and Integrative Medicine (IAIM), The University of Transdisciplinary Health Sciences and Technology (TDU), Bengaluru, India. between 2011 and 2017[cite: 7]. |
| **Results & Insights** | Successfully established a protocol for analyzing heterogeneous clinical data, proving that multidimensional SOM clustering is more effective for holistic treatments than standard binary regression models[cite: 2, 5, 18].<br><br>💡 **Key Insight:** The algorithm successfully identified specific formulations (like Nishamalaki and Vasanta kusumakara Rasa) as highly active within the largest patient clusters, providing a data-driven foundation for Ayurveda-based clinical interventions[cite: 17]. |
